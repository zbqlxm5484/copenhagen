# 다른 ChatGPT 계정용 웹캠 MCP

Windows x64 배포본 · 2026-09-23

이 ZIP은 개인별 ChatGPT 계정과 개인별 노트북에서 사용할 수 있는 설치 패키지입니다. 원래 개발자의 터널 ID, API 키, 사진, 로그, 사용자 경로 및 계정 설정은 포함하지 않습니다.

## 빠른 시작

1. Python 3.11 x64와 Python Launcher를 설치합니다.
2. ZIP을 로컬 폴더에 압축 해제합니다.
3. 본인 OpenAI 계정에서 터널을 생성하고 자신의 ChatGPT 워크스페이스를 연결합니다.
4. `Connect ChatGPT.cmd`를 더블클릭합니다.
5. 본인의 **터널 ID**를 입력하고, **런타임 API 키**를 숨김 입력창에 입력합니다.
6. 터널이 ready가 되면 본인 ChatGPT 웹에서 MCP 앱을 만들고 해당 터널을 선택합니다.

처음이라면 [전체 설치·연결 안내](USER_GUIDE.md)를 순서대로 진행하세요.

**키만 바꾸면 끝나는 방식이 아닙니다. 계정마다 터널과 ChatGPT 앱을 등록해야 합니다.**

## 실행 파일

| 파일 | 기능 |
|---|---|
| Connect ChatGPT.cmd | 설치 확인 → 로컬 MCP 시작 → 본인 키로 터널 연결 |
| Start Webcam.cmd | ChatGPT 없이 로컬 촬영 화면 실행 |
| Stop Webcam.cmd | 이 폴더에서 실행한 로컬 MCP 종료 |

프로그램은 노트북에서 실행합니다. 클라우드에 MCP를 배포하지 않지만 ChatGPT 촬영 요청의 결과 사진은 터널을 통해 ChatGPT에 전달됩니다.

API 키는 매 실행 시 입력하며 파일에 저장하지 않습니다. 터널 프로필에 저장되는 ID는 접속 비밀번호가 아닙니다. 재배포는 사용 전의 원본 ZIP을 사용하세요.
