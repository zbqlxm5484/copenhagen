# AI 작업 공간

AI 기능 개발을 위한 독립 작업 공간입니다. 현재는 역할별 최상위 폴더만 구성해 둔 뼈대 상태이며, 실제 작업이 진행됨에 따라 필요한 하위 폴더와 파일을 점진적으로 추가합니다.

## 현재 내부 구조

```text
ai/
├── README.md
├── config/     # 설정 파일
├── data/       # 학습·검증·추론 데이터
│   └── fraud_scenario_matrix.csv  # 이상거래 시나리오별 데이터·대응 매트릭스
├── docs/       # AI 관련 문서
│   └── fraud_scenario.md          # 이상거래 탐지 시나리오 정의서
├── models/     # 모델 파일 및 모델 관련 산출물
├── results/    # 실험·평가·추론 결과
└── src/        # AI 소스 코드
```

### 현재 추가된 파일

- `data/fraud_scenario_matrix.csv`: 정상·이상거래 시나리오, 위험도, Dataset 지원 여부, UCP·Rule·AI 대응 방식을 정리한 매트릭스입니다.
- `docs/fraud_scenario.md`: 이상거래 탐지 시나리오와 AI MVP 대상, 위험도 기준, UCP·Rule·AI의 역할을 정의한 문서입니다.

## 폴더 확장 방향

- `config/`: 실행 환경, 모델, 파이프라인 설정을 관리합니다.
- `data/`: 데이터 수집·정제·가공 단계에 따라 필요한 하위 폴더를 추가합니다.
- `docs/`: 아키텍처, 데이터 명세, 실험 기록 등을 문서화합니다.
- `models/`: 모델 버전, 체크포인트, 배포용 모델을 관리합니다.
- `results/`: 실험 로그, 평가 지표, 추론 결과를 보관합니다.
- `src/`: 데이터 처리, 학습, 추론, 평가 등 실제 기능 코드를 관리합니다.

## 관리 원칙

- 현재는 최상위 구조만 유지하고, 사용 목적이 생긴 경우에만 하위 폴더를 추가합니다.
- 새 폴더를 추가할 때는 이 README에 역할을 함께 기록합니다.
- 대용량 데이터·모델·자동 생성 결과는 저장소에 직접 커밋하지 않고 외부 저장소 또는 모델 레지스트리를 사용합니다.
- 비밀키, 토큰, 개인정보가 포함된 파일은 저장소에 추가하지 않습니다.
